# INIEditor

Ali Ezzahir's VB6 INI Editor (`INIEDITOR.exe`) that opens `.ini` files, lists sections and keys, and supports add/delete/change plus find-first/find-next in the value pane. Distinct from sibling `ini_editor` and `inifiletotreeview`. Open `INIEDITOR.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `Project1` (`INIEDITOR.vbp`) | VB6 | WinForms exe | INIEDITOR |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `INIEDITOR.vbp`

## Requirements

- Visual Basic 6.0 IDE
- Registered OCX/DLL dependencies referenced by the `.vbp` (may need to be installed separately):
  - `comdlg32.ocx`
